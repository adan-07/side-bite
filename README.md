# ☕ Mini Cafe | POS & Order Management System

A lightweight, high-performance Web Application designed for cafe order processing, menu management, and real-time billing administration. Built with pure modular JavaScript and powered by Firebase Firestore for real-time synchronization.

🚀 **Live Demo:** [https://mini-cafe-app.netlify.app/](https://mini-cafe-app.netlify.app/)

---

## 🌟 Key Features

### 🛍️ Customer Portal
- **Interactive Digital Menu:** Clean and intuitive UI for browsing cafe items with category filtering and instantaneous search.
- **Real-Time Item Availability:** Auto-disables and marks sold-out items instantly using dynamic backend triggers.
- **Order Tracking:** Real-time order progress updates (Pending → Preparing → Ready → Completed).

### 🔐 Admin & POS Terminal
- **Dynamic Order Management:** Live order stream dashboard with instant status updates and status filters.
- **Billing & Cashier Terminal:** Quick ticket modification, discount application, and automatic bill calculation.
- **Thermal Receipt Printing:** Built-in print engine optimized specifically for 80mm thermal paper receipts.
- **Inventory Control:** Add new products, update prices, or toggle menu item stock availability on the fly.
- **Sales & Ledger Analytics:** Comprehensive financial overview featuring daily revenue tracking and customer credit/loan ledgers.

---

## 🛠️ Tech Stack & Architecture

- **Frontend:** HTML5, Modern CSS3 (CSS Variables, Grid & Flexbox, Mobile-First Responsive Design)
- **Logic / Scripting:** Vanilla JavaScript (ES6+ Modules)
- **Database & Backend:** Firebase Firestore (Real-time Database Listeners)
- **Hosting & Deployment:** Netlify

---

## 📱 Mobile-First Responsive Design

Engineered to operate seamlessly across all device viewports:
- Single-column responsive layouts for smart mobile screens.
- Horizontal scrollable filter bars preventing UI clipping on small viewports.
- Touch-friendly action triggers tailored for handheld POS hardware and smartphones.
